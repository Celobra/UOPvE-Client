# UO:PvE client

[Download the Windows installer](https://github.com/Celobra/UOPvE-Client/releases/latest/download/UOPvE-Setup.exe)

Run **UOPvE-Setup.exe** and choose **Install UO:PvE**. Setup installs and opens the launcher, which automatically downloads ClassicUO and the game files. The initial download is approximately **2 GB**; keep the launcher open while it downloads.

Release **1.0.2** includes the custom **ClassicUO Standard Update4** client and UO:PvE login artwork. If you installed an earlier launcher, run the new setup once to upgrade it.

Open the launcher and choose **PLAY**. Enter your UO:PvE account details in ClassicUO. The launcher connects to **live.uoassets.com**, port **2593**.

**Razor is optional.** Enable **Launch with Razor** in the launcher if you want to use it. The launcher checks for new game files and maps when it opens and again before **PLAY**. Close ClassicUO before updating. **Verify / repair** can restore missing or changed game files.

Finished, verified downloads are kept if an update is interrupted and reused when you retry. The launcher displays your configured connection without repeatedly contacting the shard.

Windows with .NET Framework 4.8 is required. Players only need the installer; the other release assets are downloaded automatically.
